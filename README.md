# JAVA-PROJECT : 쇼핑몰 만들기

1. 개발 목적: 지금까지 수업에서 배운 기초 자바 프로그래밍 및 자바와 데이터베이스 연동기술을 활용해, 서비스 가능 수준의 쇼핑몰 백엔드 로직을 구현한다.

2. 주요 설계 특징:
  - 사용자 인증: 보안성을 고려한 회원가입 및 로그인 로직 구현
  - 권한 분리: 관리자(Admin)와 사용자(User) 인터페이스를 물리적으로 분리하여 시스템 보안 및 운영 효율성 제고.
  - 데이터 무결성: 오라클을 활용한 DB 연동을 통해 회원정보 및 상품 데이터를 체계적으로 관리하고 데이터의 휘발성을 방지.

3. 핵심 기능
   - Login: 가입/로그인 계정 및 계정 정보 수정 기능. (+DB)
   - Admin: 상품 등록/수정/삭제(CRUD) 및 전체 회원 관리 기능을 포함한 백오피스 구축.
   - User: 상품 조회, 장바구니 담기, 주문 처리 등 사용자 중심 입출력 시스템 구현.

4. ERD
   1. 회원 테이블 (Members): 로그인 및 권한 관리를 위한 테이블입니다.
      - member_id (PK): 회원 고유 번호 (순차적 증가)
      - user_id: 로그인 시 사용할 아이디 (Unique)
      - password: 비밀번호
      - name: 사용자 이름
      - role: 권한 구분 ('USER' 또는 'ADMIN')
      - created_at: 가입 날짜 (통계 데이터로 활용 가능)

  2. 상품 테이블 (Products): 쇼핑몰에서 판매할 아이템 정보를 담습니다.
      - product_id (PK): 상품 고유 번호
      - p_name: 상품명
      - price: 가격
      - stock: 재고 수량
      - category: 카테고리 (분류별 통계 분석 시 유용)

  3. 주문 테이블 (Orders): 사용자와 상품을 연결합니다. 
      - order_id (PK): 주문 번호
      - member_id (FK): 주문한 회원 (Members 테이블 참조)
      - product_id (FK): 주문된 상품 (Products 테이블 참조)
      - quantity: 주문 수량
      - order_date: 주문 일시

6. 개발환경
  - 언어: JAVA
  - IDE: VSCode
  - Database: Oracle
